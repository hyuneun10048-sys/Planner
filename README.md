# 🗓️ My Planner

심플한 개인 플래너 사이트 (HTML/CSS/JS만 사용, 빌드 불필요).

## 기능
- **🍀 월간 달력**: 날짜마다 네잎클로버. 완료한 할 일의 섹션 색으로 잎이 칠해지고, 다 끝내면 ✓, 남으면 남은 개수. 구글 캘린더 일정이 있는 날은 아래에 점.
- **하루 카드**
  - 상단: 날짜 + 하루 총 기록 시간 (예: `8H 10M`)
  - 📅 오늘 일정: 구글 캘린더에서 가져온 일정 (연결 시). `＋`로 일정 추가, 일정을 눌러 수정·삭제 (반복 일정 제외)
  - 왼쪽 – 섹션별 할 일: 색 막대 + 애플 이모지 + 섹션 이름 + 오늘 누적 시간. `＋`로 할 일 추가.
  - **섹션 이름을 누르면 시간 기록 시작, 다시 누르면 종료** (다른 섹션을 누르면 자동 전환)
  - 오른쪽 – 10분 단위 타임테이블 (새벽 5시 ~ 다음날 새벽 4시). 시간이 정해진 구글 캘린더 일정은 검정 블록으로 표시
  - **지난 시간 기록**: 타임테이블에서 시작 칸 → 끝 칸을 차례로 누르거나 `＋ 기록` 버튼으로 섹션·시간을 골라 추가. 기록 목록에서 항목을 누르면 시간 수정
  - **할 일 옮기기**: 할 일을 꾹 누르고 움직이면 다른 섹션으로 옮기거나 순서를 바꿀 수 있음
  - `＋ 섹션`: 이름·아이콘·색(16색 + 직접 고르기)으로 섹션 만들기
  - `편집`: 섹션 순서 변경(↑↓), 섹션을 눌러 이름·아이콘·색 변경·삭제, 할 일을 눌러 내용 수정, 할 일 삭제
- **☁️ 동기화**: 구글 앱스 스크립트를 연결하면 데이터가 내 구글 드라이브에 저장되어 모든 브라우저·기기에서 같은 내용이 보임. 여러 기기에서 동시에 고쳐도 할 일·섹션·기록 단위로 합쳐져서 서로 덮어쓰지 않음
- **🍽️ 식단 섹션**: `샐러드 350`처럼 음식과 칼로리를 적으면 섹션 옆에 하루 합계 표시. 칼로리를 눌러 수정. 시간 기록·구글 캘린더에는 안 들어감
- 연결하지 않으면 브라우저 `localStorage`에만 저장됩니다.

## ☁️ 동기화 + 구글 캘린더 설정 (5분)

내 구글 계정 안에서 돌아가는 작은 서버(앱스 스크립트)를 하나 만드는 과정이에요. 무료고, 데이터는 내 드라이브에만 저장돼요.

1. <https://script.google.com> 접속 → **새 프로젝트**
2. 기본 코드를 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣기
   (사이트의 `/setup.html` 에서 비밀번호를 넣고 **코드 복사하기**를 누르면 비밀번호가 들어간 코드가 복사돼요)
3. 맨 위 `TOKEN` 값을 **나만 아는 비밀번호**로 바꾸고 저장 (💾)
4. 오른쪽 위 **배포 → 새 배포**
   - 톱니바퀴 ⚙️ → 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인 (구글 드라이브·캘린더 접근 허용. "확인되지 않은 앱" 경고가 나오면 *고급 → 이동* 클릭 — 내가 만든 스크립트라 괜찮아요)
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사
6. 플래너 오른쪽 위 **☁️** → URL과 비밀번호 입력 → **연결**
7. 다른 기기: ☁️ → **🔗 다른 기기 연결 링크 복사** → 그 링크를 다른 기기 브라우저에서 열면 바로 연결

> 비밀번호를 아는 사람만 데이터를 읽고 쓸 수 있어요. 연결 링크에는 비밀번호가 들어 있으니 남에게 공유하지 마세요.
>
> 구글 캘린더 앱에서 **체크(표시)해 둔 캘린더**의 일정만 가져와요.
>
> `Code.gs`를 수정했다면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 해야 반영돼요 (URL은 그대로).

## 🌐 인터넷에 올리기 (어디서든 접속)

정적 파일이라 아무 곳에나 무료로 올릴 수 있어요. 코드에 비밀 정보가 없어서 공개 저장소여도 괜찮아요.

- **GitHub Pages**: 저장소 Settings → Pages → Branch 선택 → Save → `https://<아이디>.github.io/<저장소>/`
  (비공개 저장소는 유료 플랜 필요)
- **Vercel / Netlify / Cloudflare Pages**: 저장소 연결만 하면 끝 (빌드 명령 없음, 출력 폴더 = 루트)
