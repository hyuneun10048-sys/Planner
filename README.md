# 🗓️ My Planner

심플한 개인 일정 관리 사이트 (HTML/CSS/JS만 사용, 빌드 불필요).

- **월간 달력**: 날짜마다 동그라미 표시. 완료한 할 일의 섹션 색으로 채워지고, 다 끝내면 ✓, 남으면 남은 개수.
- **하루 카드**
  - 상단: 날짜 + 하루 총 기록 시간 (예: `8H 10M`)
  - 왼쪽 – 섹션별 할 일: 색 막대 + 애플 이모지 + 섹션 이름 + 오늘 누적 시간. `＋`로 할 일 추가, 동그라미로 완료.
  - **섹션 이름을 누르면 시간 기록 시작, 다시 누르면 종료** (다른 섹션을 누르면 자동 전환)
  - 오른쪽 – 10분 단위 타임테이블: 기록한 시간이 섹션 색으로 칸에 채워짐 (새벽 5시 ~ 다음날 새벽 4시)
  - `＋ 섹션`: 이름·아이콘·색(16색 + 직접 고르기)으로 새 섹션 만들기
  - `편집`: 섹션 순서 변경(↑↓), 섹션을 눌러 이름·아이콘·색 변경·삭제, 할 일 삭제
- 하루는 새벽 5시에 시작합니다 (밤 늦게 공부해도 같은 날로 기록).
- 아이콘은 애플 이모지 이미지(emoji-datasource-apple, jsDelivr CDN) 사용.
- 데이터는 브라우저 `localStorage`에 저장됩니다.

## 실행
`index.html`을 브라우저로 열면 끝. GitHub Pages / Vercel 등에 그대로 올려도 됩니다.
