# 🗓️ My Planner

심플한 개인 일정 관리 사이트 (HTML/CSS/JS만 사용, 빌드 불필요).

- **왼쪽 – 할 일**: 섹션별(📚 공부, 💼 업무, 🏠 개인 …)로 할 일 등록·완료·삭제. 섹션 추가/이름변경/삭제 가능. 날짜별로 따로 저장.
- **오른쪽 – 시간 기록**: 활동 버튼을 누르면 기록 시작, 같은 버튼을 다시 누르면 종료. 다른 활동을 누르면 자동으로 전환.
  하루 24시간 타임라인, 활동별 합계, 기록 목록 제공. `편집`으로 활동 추가/삭제.
- 아이콘은 애플 이모지 이미지(emoji-datasource-apple, jsDelivr CDN)를 사용해 어떤 기기에서도 똑같이 보입니다.
- 데이터는 브라우저 `localStorage`에 저장됩니다.

## 실행
`index.html`을 브라우저로 열면 끝. GitHub Pages / Vercel 등에 그대로 올려도 됩니다.
